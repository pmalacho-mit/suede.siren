## Installation

```bash
bash <(curl -fsSL https://suede.sh/install/release) --repo pmalacho-mit/suede.siren
```

Run it where you want the dependency. It installs `./suede.siren`, stages it, and prints what
else (if anything) has to be installed beside it.
